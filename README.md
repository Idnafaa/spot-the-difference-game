Twinview Detective — a spot-the-difference game with three scenes drawn entirely in code (a cozy room, a garden picnic, a harbor at dusk), 12 hidden changes in each, a countdown timer, hints, and full keyboard play. Two pictures, twelve lies: find them all.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step and no network: every picture is painted with canvas shapes and every sound is a generated WebAudio tone.
